# /design-brain

The command is `/design-brain`, not `/design`. Claude Code already owns
`/design`.

Design Brain is 1,119 design fundamentals, 30 sections, every entry with a
named source. It is the one extra thing on this course that was not already
a Useful Resources post. It does not install Daniel's taste.

## If the corpus is not on the machine

1. Download `design-brain_v1.zip` from the Design Brain lesson (Backblaze:
   `https://f003.backblazeb2.com/file/NavAIgate-Website/navbot-community/downloads/your-aios/design-brain_v1.zip`).
2. Unzip into their skills folder (`~/.claude/skills/design-brain` or the
   matching Cursor / Codex skills path) so `SKILL.md` and `data/` are present.
3. Restart the harness.

Do not copy Daniel's private `navaigate-plugins` house install. Members get
the zip from the lesson.

## If the corpus is present

Follow that skill: ASK, CRITIQUE, TEACH. Cite entry number and named source.
Example: body text 4.5:1, large text 3:1 — #690, WCAG 2.2 SC 1.4.3.
