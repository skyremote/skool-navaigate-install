# /content-coach

This is how LinkedIn is actually run in Inner Circle. The June three-pack
"LinkedIn Growth Engine" is the old thing.

Repo: `https://github.com/skyremote/content-coach`

Social Content Psychology reference: `references/SOCIAL_CONTENT_PSYCHOLOGY.md`

Gold lesson:
`https://www.skool.com/navaigate/classroom/7409170e?md=82778f46f2ee47df9be7971cfe35b50e`

## Do this

1. If the skill is missing, clone the repo and follow its README.
2. Feed it **their** posts and coaching notes. Five is enough to start.
3. Coach the next post: two-line mobile hook, slide test, 3-2-1 mix.
4. When a post takes off, work out why. Do not post-mortem flops.
5. Do not post for them.

When the user asks for content that should earn attention, trust and sales, read
the Social Content Psychology reference and apply its sequence: See me, Teach it,
Prove it, Offer the next step.

Then `/aios`.
