# /install-crew

The crew is **Chief of Staff 0.4.2**. That is the team. It is not the
operating system. The OS is the five plates. This command only puts a crew
on the machine.

## Do this

1. If they already have named agents, do not wipe them. Put a chief of staff
   over what exists.
2. If `skyremote/chief-of-staff-kit` is not installed, tell them:

   Claude Code:
   ```
   /plugin marketplace add skyremote/chief-of-staff-kit
   /plugin install chief-of-staff-kit@skyremote
   ```
   Then restart, then say `install the crew`.

   Cursor / Codex: clone `https://github.com/skyremote/chief-of-staff-kit`
   and follow its README. Same interview. Same 0.4.2.

3. Once the kit skill is available, follow **that** skill. Do not reinvent
   the installer here. v0.4.2 is the distribution fix after a stale install
   still said 0.2.2. Older CoS posts in Useful Resources are history.

4. When the crew is on the machine, tell them to type `/aios`.
