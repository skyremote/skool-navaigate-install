# /frontend-design

A default model page is obvious from across the room. This skill is the
pass that makes the interface look like someone chose it.

If `/design-brain` is on the machine, use it. Cite entry numbers. Do not
say "make it pop".

## Do this

1. Ask what it is (page, app screen, dashboard) and who it is for.
2. Lock three decisions before you draw: type, colour, layout. Write them
   in the project so the next pass does not drift.
3. Build the real thing in the stack they already use. Do not invent a
   second framework.
4. Critique against Design Brain if it is installed — contrast, type
   size, grid, the failure-modes checklist. Fix the hits.
5. If they want a chart, `/design-brain` section 13 and the chart gallery
   lesson. Do not invent a nineteenth chart type.

Then `/aios`.
