# /layer-5 — Build

They become the architect of what the first four plates did not eat.

## Do this

1. Name the job that is still on them after context, data, intelligence
   and the audit. Say it in one sentence they would recognise.
2. Match that job to the shelf. Do not invent a zip.
   - Thumbnails → `/thumbnails`
   - Diagrams → `/diagrams`
   - Live web / Firecrawl / Reddit / papers → `/web-scrape`
   - Podcasts → `/podcasts`
   - Transcripts → `/transcripts`
   - Proper research → `/deep-research`
   - Prose that smells like a model → `/writing-style`
   - A new app from a design → `/new-app`
   - A tool we did not ship → `/new-capability`
   - A page that looks generated → `/frontend-design`
   - Design rules → `/design-brain`
   - Their voice / memory / invoices → `/your-voice` `/your-brain` `/your-ops`
3. If nothing on the shelf matches, that is `/new-capability` or `/new-app`.
4. Then `/aios` so they can pick the next one themselves.

The shelf is the library. It is theirs to pick from. Do not hide it.
