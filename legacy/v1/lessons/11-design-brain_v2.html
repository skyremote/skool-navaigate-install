Listen to this lesson in my voice

I sat with a friend and we wrote this down properly — 1,119 design fundamentals, 30 sections, and every entry has a named source. Muller-Brockmann. Rams. WCAG. Tufte. Not “make it pop”. An entry number you can argue with.

That is Design Brain, and it is in annual on purpose, because if we only put one extra thing on this course that was not already sitting in Useful Resources, this would be it. You install the corpus. The agent cites it when you build a page, a deck, a chart, a thumbnail. It does not install my taste.

What you actually get

  • 1,119 entries you can search offline
  • 30 sections, from first principles through type, grid, colour, accessibility, data viz, and the failure-modes checklist
  • Each entry: the rule, why it exists, how to apply it, a pitfall, a number where there is one, and the source
  • A critique mode — violation, entry number, the rule, the source, the fix

Example: body text needs 4.5:1 against its background, large text needs 3:1 — entry #690, WCAG 2.2 SC 1.4.3. WebAIM’s February 2026 scan of a million home pages still found low-contrast text on 83.9 percent of them.
