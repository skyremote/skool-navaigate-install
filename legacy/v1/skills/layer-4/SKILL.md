# /layer-4 — Automate

The only honest start is a task audit of what they actually did last week.

ProductivityOS was a February GTD inbox with `/process` and `/review`.
That is not the path.

## Do this

1. List the jobs that ate the week. They name them. You do not invent a
   busy week.
2. Mark the real repeats.
3. Automate those only. n8n, a cron, a skill, a scheduled agent — whatever
   they already run. Do not rip out a working cron to install a zip.
4. Everything else stays human for now.

Then `/aios`. Tell it the one job they automated.
