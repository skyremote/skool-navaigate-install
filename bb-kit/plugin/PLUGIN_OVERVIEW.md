## What you get

An **AIOS course** page in the bb sidebar with every prompt from YOUR AIOS 2.0, the NavAIgate course on building an AI operating system for your business. There are fourteen modules with one to three prompts each. Each prompt tells Claude what to set up in your AIOS folder, what to check, and how to show you the result: an inline report in the chat, the chat moved to a Review lane, and a five-line summary.

## How it works

Open a module and press **Start chat** to start a Claude chat in your AIOS project with that prompt, or **Copy** it and paste it into any chat. **Save all to Prompt Library** stores every prompt in bb's built-in Prompt Library, so `Ctrl+R` in any chat box finds them when you type "AIOS".

Agents and terminals use `bb aios-kit list`, `bb aios-kit show <id>`, `bb aios-kit start <id>` and `bb aios-kit star`.

## Requirements

Claude Code installed and signed in. Each prompt installs the free AIOS pack it needs from the public repository https://github.com/skyremote/skool-navaigate-install. Prompts run on your own Claude plan.
