# AIOS Starter (bb plugin)

The YOUR AIOS 2.0 prompt library inside bb. Installed by the starter kit (`bb-kit/install.sh`), or on its own:

```sh
bb plugin install git:https://github.com/skyremote/skool-navaigate-install.git@main --subdirectory bb-kit/plugin --yes
bb plugin enable bb--prompt-library
bb aios-kit star
```

- `server.ts`: the library over RPC, `bb aios-kit` (list, show, start, star).
- `app.tsx`: the "AIOS course" sidebar page.
- `prompts.ts` and `prompts.json`: generated by `bb-kit/scripts/build_prompts.py` from `bb-kit/prompts-src/`. Do not edit them by hand.
- `skills/aios-starter/SKILL.md`: tells agents how to use `bb aios-kit`.

Build and check: `npm ci && npx tsc --noEmit -p . && bb plugin build`.
