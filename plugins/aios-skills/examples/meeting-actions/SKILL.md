# Meeting actions

## When to use
Notes or a transcript from a meeting, and the person wants the actions out of it.
Stay quiet for summaries, minutes or emails: this skill only lists actions.

## Steps
1. Read the notes. Find every sentence where someone agrees to do something.
2. Write one line per action, numbered, in this exact shape:
   `1. <verb> <what> | Owner: <name> | Due: <date or "not set">`
3. Use the name exactly as it appears in the notes. If nobody owns it, write `Owner: not set`.
4. Convert relative dates ("next Friday") only if the meeting date is in the notes.
   Otherwise keep the words as written.
5. Under the list, add `Missing:` with any action that has no owner or no date.

## Check
Count the lines. Every line has `Owner:` and `Due:`. If one does not, fix it before you answer.

## Never
- Never invent an owner or a date. "not set" is the honest answer.
