# aios 2.0.0

The start pack. Install this one thing and it works straight away. It knows every pack in
the repository from `catalogue.json`: each pack's module, dependencies, hooks, MCP servers
and settings. It installs whatever you need, when you need it, and teaches each module
inside your own folder.

`aios` declares no dependencies. Every other pack depends on it.

## Use it
- `/aios` (or `/aios:aios`): what you have, your next module, one action.
- `/aios learn <module>`: walk the module's tour one step at a time, with a check after each step.
- `/aios` with a request such as "set up my brain": finds the pack and installs it.

The same actions work in a terminal, Codex and Cursor through `aios-guide`:

```sh
aios-guide next
aios-guide list
aios-guide find set up my brain
aios-guide install aios-brain
aios-guide verify aios-brain
aios-guide learn 1
aios-guide progress --complete 1
```

## Install
Claude Code: `claude plugin install aios@navaigate-aios`, then `/reload-plugins`.
Codex and Cursor: `./install.sh aios` from your clone. That links the `aios` skill into each
harness (call it with `$aios` in Codex and `/aios` in Cursor), links `aios-guide` into `~/.local/bin`, and records the clone's path so later
installs work from any folder.

## Files
- `skills/aios/SKILL.md`: the `/aios` skill.
- `bin/aios-guide`, `scripts/guide.py`: the command.
- `scripts/status.py`: the read-only inventory across Claude Code, Codex, Cursor and `~/.agents`.
- `catalogue.json`: generated by `scripts/build_catalogue.py`. Do not edit it by hand.
- `TOUR.md`: the module 1 tour.
