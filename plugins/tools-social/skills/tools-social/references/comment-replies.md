# Comment-for-link replies (Instagram and Facebook through Blotato)

1. **Before the post goes live:** extract every keyword the caption asks for ("comment GUIDE"), including spelling
   variants. Confirm the exact public URL gives what the post promises. Never guess a link from a keyword.
2. **Check what Blotato can do now.** Read the current tool list. Publishing access does not mean comment or message
   access. If replies cannot be automated on a platform, put the link in the caption, or name the person who will reply.
3. **One rule per campaign.** Scope a generic keyword ("link", "guide") to the one post. Account-wide scope only for a
   unique keyword with one destination. Never change an unrelated rule. Read the rule back after creating it.
4. **Keep a private record** beside the post files: platform, caption, keywords, resource URL, reply text, rule id,
   post id and URL, and what has been verified.
5. **Prove it end to end.** An active rule is not a test. A fresh comment from another account must create a run and
   a message. Never fake engagement from the member's own account. If no fresh comment exists, say it is pending.
6. **Missed requests:** send backfill only when the member asks. Check earlier messages first, so nobody gets two.
   Respect each platform's reply window; an expired window is a manual follow-up, not a workaround.
