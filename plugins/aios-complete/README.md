# aios-complete 2.0.0

The whole YOUR AIOS framework in one install. This plugin holds no skills of its own.
It depends on the start pack `aios`, the brain `aios-brain` and every core pack for
modules 2 to 11, so installing it installs all of them in one go. Shelf packs
(module 12) stay optional: add the ones you want with `/aios`.

Claude Code:

```sh
claude plugin install aios-complete@navaigate-aios
```

Then type `/reload-plugins` in an open session, or restart Claude Code.

Codex and Cursor, from your checkout of this repository:

```sh
./install.sh aios-complete
```

The installer works out the order from each pack's dependencies and installs each
pack once. Run `./install.sh aios-complete --check` to prove every pack is in place.

The dependency list is generated by `scripts/build_catalogue.py` from the marketplace,
so it always matches the packs that have shipped. Do not edit it by hand.
