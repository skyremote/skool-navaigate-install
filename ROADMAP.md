# YOUR AIOS 2.0 roadmap v2

Members install one thing, the start pack `aios`. It reads `plugins/aios/catalogue.json`
and installs each pack when the member reaches its module, with its dependencies.
`aios-complete` installs the whole core path (modules 1 to 11) in one go. Every pack
except `aios` depends on `aios`; `aios` depends on nothing, so there is no cycle.
Installing a pack never marks a lesson complete: only the member confirms that.

The catalogue is generated by `scripts/build_catalogue.py` from the marketplace and
each pack's `plugin.json`. A pack appears for members once its stream's
`MARKETPLACE_ENTRY.json` is merged and `--merge-entries` has run.

## Module 12 shelf

Shelf packs are named `shelf-<job>`. The first two built are `shelf-video` and `shelf-decks`.

| Pack | First useful job | Boundary |
|---|---|---|
| shelf-video | Cut a recording and prepare a film | Generic cutroom/NavMotion process; member media |
| shelf-decks | Build and verify a presentation | Member brand and figures |
| shelf-invoices | Build an invoice from member details | No shared tax, register or bank details |
| shelf-voice | Write in the member's voice and add narration | Member samples and authorised voice account |
| shelf-design | Thumbnails, diagrams, frontend design, design rules, charts | Check corpus count/licence before shipping |
| shelf-research | Search, extract, podcasts, transcripts, ask your numbers | Member sources and optional paid keys |
| shelf-content | Content coach, pipeline, daily brief and executive briefs | Member brand, numbers and accounts |

The audit keeps "Ask your numbers" on the shelf. It belongs to shelf-research as
an optional data lesson rather than disappearing because there is no core data
module. The old Social Content Psychology and Chart gallery lessons stay under
content/design; neither is a separate 1.x skill directory.

## Version and migration boundary

The new manifests are 2.0.0 under plugins/aios and plugins/aios-brain. The old
first-generation files remain at their original skills/, references/
and templates/ paths. Course lessons and videos live on Skool, not in this repo. The marketplace retains skool-navaigate-install at ./,
using its original 0.1.0 manifest version. Existing symlinks remain valid after
pulling this branch. There is no legacy/v1 directory.

V1 stays installable for six months, until **26 April 2027**, with fixes only.
The root installer with no arguments retains the v1 behaviour. The 2.0 /aios
inventory detects v1 links and offers a guided move; it never migrates merely
because v1 was detected. An explicitly reviewed `./install.sh aios --migrate-v1`
preserves conflicting start links in member-owned backups and links the 2.0 start
pack. All other v1 skills, the Claude v1 link and old marketplace ID remain.

All 16 code-review findings have dedicated regression cases in tests/, including
the v1 link survival contract.
