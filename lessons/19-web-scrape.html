Listen to this lesson in my voice

Ask Claude to look something up and half the time you get a thin summary, a 403, or a page that was mostly JavaScript and came back empty. The built-in search is fine for a quick fact. It falls over the moment the page is doing anything interesting, and the modern web is doing a lot.
This is how we read the web on the machine today. Two providers, one helper.

  • Exa — semantic search. You describe what you want and you get the pages that actually match, with highlights or full text when you need them.
  • Firecrawl — a real headless scrape. It runs the JavaScript and hands back clean markdown. That is the one for a SPA, a docs portal, a pricing page behind Cloudflare.

Rule of thumb: Exa to find, Firecrawl to extract. If you already have the URL, go straight to scrape.

The honest cost

Firecrawl and Exa run on credits. The default tools are free. If you are occasionally checking a fact, stay on the defaults. The moment you are doing competitor research, pulling a docs section, or reading sites at scale, the defaults cost you more in wrong answers than the keys cost in credits. Both have a free tier. Prove it to yourself.

What else is on the same helper

  • Academic — OpenAlex and Unpaywall, papers and free PDFs
