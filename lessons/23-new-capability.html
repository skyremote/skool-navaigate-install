Sooner or later you hit the edge of the shelf. Content is covered, the brief is running, and then the business asks for HubSpot, or an internal API that only exists inside your company. There is no module for that, and there never will be, because it is yours.
Most people stop there and assume a new integration means becoming a developer. It does not. This skill walks you through creating the next capability — a standing piece of plumbing the OS can reach for, not a one-off script that rots in a folder.

Four steps, in order

  1. Interrogate. What data do you want out, where does it live, what authenticates you, how often. Most failed integrations fail here, in the vagueness.
  2. Find the surface. Official API, unofficial, CLI, or scrape. Pick the one least likely to break in three weeks.
  3. Build the wiring. A SKILL.md and the smallest helper. Keys in ~/.claude/.env under your names. Nothing runs you have not seen.
  4. Install it. Into your skills folder, the same way the rest of this course landed.

Start with something you can verify in under a minute — the last ten items on a public feed. Then the CRM link. The first one teaches you the loop. The second one is the same conversation with higher stakes.
Type /new-capability and describe the gap. Type /aios when you can repeat the command.
