A default model page is obvious from across the room. Same card grid, same inter font, same purple gradient, same empty state that says get started. If you are going to ship an interface a client will keep, you have to choose it.
This module is that pass. You lock type, colour and layout before you draw, you build in the stack you already use, and if Design Brain is on the machine we critique against the corpus — contrast, type size, grid — with entry numbers you can argue with. Not "make it pop".
If you are on a chart, start in Design Brain section 13 and use the gallery we already have. Do not invent a nineteenth chart type.
Type /frontend-design with the page you are actually shipping this week. Type /design-brain if you have not installed the corpus yet. Type /aios when the page would survive a screenshot.

When you want this in a tab of your own, type /aios-coach. You build it, you put it online, your key. It already knows this course. It is not on navaigate.dev yet.
