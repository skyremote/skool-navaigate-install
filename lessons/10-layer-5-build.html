Layer 5 is build. The first four plates ate a lot of the week — context, numbers you can ask, meetings that do not vanish, the jobs you actually repeat. What is still on you after that is the thing we design for.
That leftover job is not a mystery word. It is the thumbnail that still holds up every release, or the architecture you keep describing with your hands, or the HubSpot link nobody shipped, or the app you keep opening Claude for and watching it improvise. Name it in one sentence you would recognise.
Type /layer-5. We name that job. Then we match it to the shelf — the same modules we built for these lessons, rewritten for how we work on the machine today. You pick. You do not download a zip into module-installs/.

  • Thumbnails → /thumbnails
  • Diagrams → /diagrams
  • Live web / Firecrawl → /web-scrape
  • Podcasts → /podcasts
  • Video transcripts → /transcripts
  • Research done properly → /deep-research
  • Prose that smells like a model → /writing-style
  • A new app from a design → /new-app
  • A tool we did not ship → /new-capability
  • A page that looks generated → /frontend-design
  • A coach tab that already knows the course → /aios-coach

If nothing on that list is the job, that is still /new-app or /new-capability. We componentize that, and we stop.
Type /aios and pick the one that is costing you the most time this week.
