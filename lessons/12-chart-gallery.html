Listen to this lesson in my voice

I kept losing a day to the same question — which charting library do we put in this product — and a list of names does not answer it, because you cannot feel the interaction, and you cannot steal the render function.
So I built the comparison I wanted. 19 live charts. 8 libraries. Dummy data. Dark and light. Filters for distribution, flow, hierarchy, ranking, real-time, relationship and trend. The code behind every card. Dependencies vendored, so it runs offline.
Download the 19-chart gallery (chart-gallery-offline_v1.zip)
This lesson is not a post to admire. Download the zip, open chart-gallery_v1.html in your browser, and click something.

Do this, in order

  1. Unzip and open the gallery. Hover, zoom, scrub, open Code on one card.
  2. Pick the chart you would actually ship this month.
  3. Ask Design Brain to critique that chart against section 13. Start with #496 and #511. If the title names the variables instead of the finding, that is #534.
  4. Choose one default. My current shortlist: ECharts 6 as the default, shadcn/Recharts when you are already in that React desk, uPlot for dense telemetry, Lightweight Charts when people need to scrub a premium series, D3 only when the chart is the product.

The same gallery is in Useful Resources as Steal my chart gallery. Annual puts it on the OS path, next to Design Brain.
