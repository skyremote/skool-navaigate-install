One search box is not research. You get the first page of whoever paid for it, and you call it done. This module is the pass we actually run when the question is "research this properly".
Scope the question in one sentence you agree with. Recon each source as hot, warm or cold — web, Reddit, papers, Substack, YouTube if you asked. Run the live ones. Exa to find, Firecrawl to extract. Academic is keyless. Reddit through Composio if you have it. Supadata only when you want the video evidence, because it is paid. Then a critic pass: recency, source type, specificity, independence. Then a synthesis with confidence labels and quotes, not a flatten.
Same helper as /web-scrape. Same keys in ~/.claude/.env. Type /deep-research with the question you would actually pay to have answered. Type /aios when the synthesis has sources you can click.

When you want this in a tab of your own, type /aios-coach. You build it, you put it online, your key. It already knows this course. It is not on navaigate.dev yet.
