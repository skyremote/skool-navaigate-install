Layer 1 is context. The machine should know the business before it starts guessing.
We start with the file you already have — CLAUDE.md, AGENTS.md, whatever your harness reads — and a first pass at your voice, not mine.
Type /layer-1. If the folder is empty, we write the smallest useful context file from what you tell it. If you are halfway, we read what is there and we only fill the holes. If you already have a tight context file, we leave it and we move.
Git belongs here if you already use it. We do not force a remote on a folder that is not ready.
When the file would make sense to a stranger on your team, type /aios again.

When you want this in a tab of your own, type /aios-coach. You build it, you put it online, your key. It already knows this course. It is not on navaigate.dev yet.
