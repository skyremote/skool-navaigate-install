Written by Daniel Wright · NavAIgate

Most content teaches too early. It starts with the advice, the framework or the list of tips before the viewer has felt that the creator understands what is actually going on.

The stronger sequence is simple: See me, Teach it, Prove it, Offer the next step. The point is not to make another neat formula. The point is to change what the viewer feels while they are watching.

See me

Name the private frustration, insecurity or desire the right person is already carrying. If you are selling, start with the buyer's lived problem, not your product.

Teach it

Explain one mechanism in plain language. Use curiosity and an open loop, but close the loop by teaching something useful. Do not hide behind five tips.

Prove it

Show the personal result, customer result, worked example or live demonstration you can honestly show. The video should demonstrate the lesson while it teaches it.

Offer the next step

Give one useful action or one relevant offer. One clear CTA is enough.

Install it

This lesson is part of the public AIOS install repository. In Claude Code, add the marketplace and install the plugin:

/plugin marketplace add skyremote/skool-navaigate-install
/plugin install skool-navaigate-install@navaigate-aios

For Cursor or Codex, clone the repository and run ./install.sh:

git clone https://github.com/skyremote/skool-navaigate-install.git
cd skool-navaigate-install
./install.sh

Restart the harness. Then type /content-coach in Claude or Cursor, or $content-coach in Codex.

Use it this week

Ask: What are you doing this week? Then give the Coach the audience, offer, private problem, proof and platform. Ask for the hook, one mechanism, the demonstration, the CTA and a talk track for speaking over the content.

The method comes from the Social Content Psychology research: make the viewer feel specifically seen and understood, then earn the right to teach and sell.
